# RPM Prompt Studio

Generator prompt AI untuk menyusun **Rencana Pembelajaran Mendalam** yang terintegrasi dengan **Papan Interaktif Digital (PID)** dan **Rumah Pendidikan** Kemendikdasmen.

Guru mengisi formulir, lalu aplikasi menyusun prompt lengkap secara langsung. Prompt itu kemudian ditempel ke Gemini, ChatGPT, atau Claude untuk menghasilkan dokumen perencanaan.

## Cara memakai

1. Buka halaman aplikasi di browser (perlu koneksi internet).
2. Isi kartu 1–5. Kolom bertanda **WAJIB** harus diisi; bagian yang belum diisi tampil merah muda di pratinjau.
3. Pilih target AI: **Gemini**, **ChatGPT**, atau **Claude**.
4. Klik **Salin Prompt**, atau **Buka di …** untuk menyalin sekaligus membuka situs AI-nya, lalu tempel (Ctrl+V).
5. Prompt juga bisa disimpan lewat **Unduh (.txt)**.

Tombol **Contoh Isian** memuat contoh lengkap (Biologi Kelas X) untuk melihat bentuk prompt yang sudah jadi.

## Catatan

- Semua isian disimpan di browser masing-masing pengguna; tidak ada data yang dikirim ke server.
- Aplikasi berupa satu file `index.html` (HTML, Tailwind CSS, JavaScript).
